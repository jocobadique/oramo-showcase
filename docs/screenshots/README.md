# Screenshots

Images used by the main [README](../../README.md). They're captured at 1440×810 from the live demo's seeded clinic, "Ngiti Dental Care", in Oramo's own lagoon brand colors. Each clinic can set its own color (white-label theming). The demo-mode notice banner, scrollbars and the notifications page's sticky save bar are hidden in the captures.

| `booking.png`       | Public booking page: clinic-branded date and time step (Asia/Manila)         |
